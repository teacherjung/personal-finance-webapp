# 已退役（本機保留，不進版控）

放**已經不用、之後可能會刪**的東西。

## 為什麼不叫 `archive`

`docs/archive/` 已經存在，而且意思**相反**：那裡是「**進版控、永久保存**」的退役文件。
兩個同名不同意思會害人猜錯——那正是 2026-08-03 那支改名 PR（#387）在修的病。

## 為什麼不直接刪

這裡的東西都是**未追蹤檔**：Git 從來沒存過它們 ⇒ **刪掉就真的沒了**。
搬進來是可逆的、刪除不是。**先把不可逆的決定換成可逆的**，過一陣子確定沒用到再刪。

## 什麼時候可以刪

**用不到就刪，但要有依據。** 建議的判準：搬進來滿一個月、期間沒有任何人打開過 ⇒ 刪。
刪之前先確認：那個決定本身有沒有記在別的地方（`review-loop.js` 的「為什麼不做成工具」已經寫在 `審查與合併程序.md` 裡，所以刪掉只會失去程式碼，不會失去理由）。
