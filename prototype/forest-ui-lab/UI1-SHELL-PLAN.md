# UI1 正式外殼與設計 token

## 目的

把已驗收的森林實驗室視覺語彙，先落到正式 App 的共用外殼；不改任何頁面資料、路由或計算。

## 本 PR 預約範圍

- `public/styles.css`：根層色彩、線條、陰影、圓角、頁面背景、側欄、導覽、共用卡片與手機外殼。
- `public/index.html`：只有品牌名稱、副標或外殼所需的無資料結構；若純 CSS 足夠則不修改。
- `prototype/forest-ui-lab/UI1-SHELL-PLAN.md`：本施工契約。

## 明確排除

- 不改 `public/app.js`、`public/modules/**`、`public/stock-research.css`。
- 不改 API、後端、資料庫、公式、金額格式與路由。
- 不把森林插圖放進每一頁；UI1 只建立一致的紙張、深褐描邊、暖金側欄與四色訊號系統。
- 不新增拖拉、縮放、版面保存或月份切換。

## 驗收

1. 正式 App 所有既有路由仍可重新載入，console error 為 0。
2. 桌機與手機沒有頁面水平溢出；表格自己的橫向捲動維持原狀。
3. 導覽、按鈕、表單、彈窗與鍵盤焦點仍清楚可用。
4. 只改外觀；DOM id、事件入口與資料輸出不變。

## 回復

這支若不符合視覺驗收，整支 PR 不合併即可；沒有資料搬家或後端狀態需要回復。
