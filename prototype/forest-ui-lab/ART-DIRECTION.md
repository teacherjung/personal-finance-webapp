# 榮祥森森林 UI 美術規格

這份原型只用合成資料，目的不是重畫正式 App，而是先驗證「完整資訊可以住在卡通森林裡」。在 William 確認前，不修改 `public/`、API、資料庫或既有頁面模組。

## 一、畫面原則

1. **環境承載品牌，不替數字評分**：森林維持一致、溫暖的主視覺；本月淨資產變動與近十二個月趨勢以明確數字和圖表呈現。
2. **資料仍是 HTML**：金額、標題、按鈕、表格與圖表不畫進插圖，確保可搜尋、可讀取、可更新。
3. **插圖負責情緒與方向**：森林主場景承載狀態；工作區仍用清楚的紙張、表格與控制項。
4. **卡通感不靠犧牲對比**：深褐描邊、白紙工作面、綠／珊瑚／霧藍／金黃四組訊號色並用。
5. **手機不是縮小桌機**：主場景改成直向構圖，表格保留橫向捲動，控制項換行但不重疊。

## 二、視覺語彙

| 元素 | 規則 |
| --- | --- |
| 世界背景 | William 提供的投資森林：樹木、花石與中央路徑；總覽先固定使用明亮版本，不隨單月數字換景 |
| 工作表面 | 暖白紙張、2px 深褐線、6–8px 圓角、硬邊金黃陰影 |
| 常用操作 | 沿用專案既有線條圖示；按鈕不另畫成圖片 |
| 數據圖 | Chart.js；線色與面積色沿用既有分類色盤方向（`public/modules/theme.js`） |
| 角色 | 所有角色頭像一律使用 William 提供的小森森表情，不使用字母頭像或通用吉祥物；只出現在提醒、空狀態與完成狀態，不遮住表格 |
| 動效 | 只保留不影響判讀的嚮導微動，並遵守系統的減少動態設定 |
| 桌機版面 | 12 欄固定格線；淨資產與收支圖並列，其餘內容依重要性固定順序 |
| 手機版面 | 一律單欄滿寬，圖表、提醒、持股與估值依固定順序往下閱讀 |

## 三、素材分層

- `場景`：總覽、收支、投資、研究、設定各一張寬景；WebP／PNG。
- `角色狀態`：平靜、提醒、完成、思考、空狀態、載入、錯誤、歡迎共八張透明圖。
- `裝飾零件`：葉片、花、石頭、木牌、紙膠帶、印章等；只補空白，不承載功能。
- `功能圖示`：沿用 `public/modules/icons.js`，未來若換 Lucide 也維持同一個介面。
- `資料圖表`：Chart.js 與 HTML/CSS，不生成點陣圖。

## 四、淨資產資訊設計

- `assets/forest-return-positive.webp`：William 提供的晴朗投資森林原圖。
- `assets/guide-return-positive.webp`：微笑表情，用於淨資產增加情境。
- `assets/guide-return-neutral.webp`：中性表情，用於接近持平情境。
- `assets/guide-return-negative.webp`：審慎思考表情，用於淨資產減少情境。

本月摘要只顯示最新月份：淨資產金額、較上月底的金額變動與百分比。總覽不提供月份切換；歷史判讀改由「近 12 個月淨資產」折線圖負責，並與「近 12 個月收支」並列。這比逐月重播整個頁面更適合比較趨勢，也避免月份控制搶走森林主場景。

正式接線時，當月淨資產取既有 snapshot 的 `netWorth`，與上個月 snapshot 比較；十二個月趨勢取相同 snapshot 序列。首筆月份必須顯示「尚無比較基準」，不可補零或推算。「沒有前一筆」與「上月底淨資產為 0」是兩種狀態：後者仍顯示金額變動，但明說無法計算有意義的變動比例。淨資產變動包含收支、投資市值、匯率與負債變化，任何位置都不得寫成投資報酬率。

森林原圖與嚮導表情由 William 提供；陰天、雨天版本由 Codex 內建影像工具依原森林構圖製作。財金文案不得把報酬率寫成「長高」、把風險寫成「生病」；森林語彙只負責導覽與視覺情緒。

## 五、版面與無障礙契約

- 卡片順序與尺寸由設計固定，不提供拖曳、縮放、聚焦或版面保存；使用者不必先整理介面才能讀資料。
- 可操作元件保留清楚的鍵盤焦點；篩選、幣別、滑桿與對話框不依賴滑鼠。
- 正負狀態同時用文字、正負號與數字表達，不把紅綠色當成唯一線索。
- 圖表 canvas 提供可朗讀的摘要；動畫遵守系統的「減少動態」設定。

## 六、分段施工

1. **UI0 森林 UI 實驗室（本 PR）**：合成資料總覽、桌機／手機、首批素材與互動元件。
2. **UI1 外殼與 token**：只搬側欄、背景、字體、色票，不碰頁面資料流程。
3. **UI2 正式總覽**：把既有 dashboard 與 snapshot 資料接到森林狀態，不改公式。
4. **UI3 高密度工作面**：銀行收支、信用卡與持股表；逐頁固定輸入輸出考題。
5. **UI4 個股研究**：沿用既有頁籤契約，替換外觀與空狀態。
6. **UI5 全站狀態素材**：載入、空白、錯誤、完成與危險提醒。
7. **UI6 收官**：手機、鍵盤、對比、列印與所有路由瀏覽器回歸。

每一步一支獨立 PR。Codex 不自行合併；Claude 優先複審。若正式功能同期施工，該頁 UI 延後，不共改同一檔。
