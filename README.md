# 個人理財中心

一個**只在你 Mac 本機執行**的個人理財網頁。所有資料存在 `data/store.db`（SQLite，Node 內建引擎），永遠不會上傳到任何雲端。

## 功能
1. **總覽** — 淨資產、本月現金流、所有提醒集中一頁；淨資產走勢圖、資產配置圓餅圖
2. **收支記帳** — 收入/支出分類記錄、月結餘、支出分類分析、現金流提醒
3. **資產配置** — 各帳戶餘額、實際 vs 目標配置、偏離時提醒再平衡
4. **IB 投資組合** — 透過 IB Flex Query 唯讀同步持倉，集中度與閒置現金提醒
5. **訂閱追蹤** — 信用卡、金額、週期、下次續費日、email，即將續費提醒
6. **保險追蹤** — 繳費時程、保障內容、要保／被保／受益人、保障期限、繳費提醒

## 啟動方式
需要 **Node.js 22.13.0 或更新版本**（使用 Node 內建的 SQLite）。雙擊啟動時會自動檢查版本，若不符合會顯示安裝指引，不會直接閃退。

**最簡單**：在 Finder 中雙擊 `start.command`，瀏覽器會自動打開。

或在終端機：
```bash
npm install   # 第一次
npm start
```
然後打開 http://localhost:4321

## 重要說明
- **隱私**：伺服器只在 `127.0.0.1` 監聽，外部與同網路裝置都連不到。
- **備份**：到「設定」頁可匯出 / 匯入整份資料的 JSON。每次啟動會自動產生完整快照 `store.db.bak`；舊版的 `store.json` 在升級後保留作為搬家前備份。
- **範例資料**：第一次啟動會載入 `data/seed.json` 的範例（含家人保單、訂閱等示意資料），請逐步替換成你的真實資料。要全部清空，刪掉 `data/store.db`（連同 `.bak`/`-wal`/`-shm`，以及舊版 `store.json` 若還在）再重啟即可。
- **IB 串接**：到「設定」頁填入 Flex Token 與 Query ID。Flex Query 是 IB 官方的**唯讀**報表服務，不涉及任何下單或轉帳權限。

## 技術
Node + Express（後端）＋ 原生 JS SPA ＋ Chart.js（前端），零建置步驟、相依套件極少，方便長期維護。
