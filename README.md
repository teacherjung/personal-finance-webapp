# 個人理財中心

一個個人理財網頁，**兩種模式**：

- **LOCAL（預設，日常使用）**：只在你 Mac 本機執行，資料庫預設存在 `data/store.db`（SQLite，Node 內建引擎）；自訂 `STORE_FILE` 時，以啟動終端顯示的設定定位為準，不上傳任何雲端。
- **HOSTED（多人上線，建置中——C6 首次部署及對抗驗收完成，後續項與 C7 尚未完成）**：部署在 Render、資料存 Supabase Postgres（RLS 租戶隔離），機密欄位加密存放或剝除、一律不進瀏覽器。開關＝`NOTEASY_HOSTED=1`，不開＝與純本機版零差別。

## 功能
1. **總覽** — 淨資產、本月現金流、所有提醒集中一頁；淨資產走勢圖、資產配置圓餅圖
2. **收支記帳** — 收入/支出分類記錄、月結餘、支出分類分析、現金流提醒
3. **資產配置** — 各帳戶餘額、實際 vs 目標配置、偏離時提醒再平衡
4. **IB 投資組合** — 透過 IB Flex Query 唯讀同步持倉，集中度與閒置現金提醒
5. **訂閱追蹤** — 信用卡、金額、週期、下次續費日、email，即將續費提醒
6. **保險追蹤** — 繳費時程、保障內容、要保／被保／受益人、保障期限、繳費提醒

## 啟動方式
需要 **Node.js 22.23.1 以上的 22 系列，或 24.0.0 以上版本；不支援 Node 23**（使用 Node 內建的 SQLite，主檔以 URI 禁止自動補建）。雙擊啟動時會自動檢查版本，若不符合會顯示安裝指引，不會直接閃退。

**最簡單**：在 Finder 中雙擊 `start.command`，瀏覽器會自動打開。

或在終端機：
```bash
npm install   # 第一次
npm start
```
然後打開 http://localhost:4321

## 重要說明
- **隱私（LOCAL 模式）**：伺服器只在 `127.0.0.1` 監聽，外部與同網路裝置都連不到。（HOSTED 模式本來就要對外服務，防線改為登入牆＋RLS 租戶隔離＋機密加密或剝除。）
- **備份（LOCAL 模式）**：到「設定」頁可匯出 / 匯入整份資料的 JSON。開庫時會嘗試產生啟動快照（有效主檔名後加 `.bak`）；失敗會留本機警告並保留前一份，存在不代表最新或有效。舊 JSON 搬家來源若存在，成功搬入後保留原檔。人工還原條件與保存順序見[資料與儲存契約](docs/contracts/data-storage.md#本機檔案操作一律經櫃檯)。（HOSTED 模式沒有本機快照，備份＝Supabase Pro 每日備份＋設定頁手動匯出。）
- **範例資料（LOCAL 模式）**：第一次啟動會載入 `data/seed.json` 的範例（含家人保單、訂閱等示意資料），請逐步替換成你的真實資料。要全部清空，刪掉 `data/store.db`（連同 `.bak`/`-wal`/`-shm`，以及舊版 `store.json` 若還在）再重啟即可。（HOSTED 新帳號從全空開始，不含範例資料。）
- **IB 串接**：到「設定」頁填入 Flex Token 與 Query ID。Flex Query 是 IB 官方的**唯讀**報表服務，不涉及任何下單或轉帳權限。

## 技術
Node + Express（後端）＋ 原生 JS SPA ＋ Chart.js（前端），零建置步驟、相依套件極少，方便長期維護。
測試用 Node 內建的測試工具（`npm test`），不需要另外安裝測試框架。
