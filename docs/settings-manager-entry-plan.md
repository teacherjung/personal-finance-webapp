## 範圍

承接既有 GS-F04 與 AGENTS.md 理財優化續作授權，基底為 #742 合併提交 `480fae410ffc710a45bbfad1315a71453f7c9ea9`。Codex 實作、官方 Grok 複審，掃描維持暫停。

本支限設定頁支出分類、收入分類、版面規則卡、銀行收支學習、摘要與備註套用、內轉分類的初次讀取與開窗接縫。分類／內轉保存、管理器刪除續行、店名規則、體檢及其他設定流程另支處理。保留端點、資料投影、標題、尺寸、文案與關閉方式，不改後端、帳務或外觀。

## 基線證據

擷取正式六入口呼叫端，在 API 替身延遲期間改變合成網址，再放行成功或失敗；成功仍呼叫開窗函式、失敗仍通知。此為有限呼叫端重現，不是完整模組、DOM、真 HTTP 或資料保存證據。正式回歸須用獨立合成 LOCAL 帳本與完整模組補足。

## 技術裁示與施工邊界

依指定 GPT-6.1 Sol／xhigh 的唯讀技術裁示，六入口共用最後有效開啟意圖序號；公開完整裁示於本支 PR 留痕。接受入口前核原按鈕、設定頁身分、完整 hash 與換頁世代；失效舊事件不得發 GET 或撤銷新意圖。

接受後取唯讀彈窗觀察戳，不提前搶占或打開等待窗。成功及失敗續行核意圖序號、hash、換頁世代、原頁面及彈窗根節點身分與觀察資格。同頁背景重畫移除原按鈕不撤銷已接受讀取；開窗前的排序與保存後交接不可混用。同步開窗自身取得所有權不應被外層當成過期錯誤而吞掉。

最新意圖失敗不復活舊成功；有效失敗保留各入口錯誤前綴，實際再次點擊可重試。不得新增寫入、自動重試、共用框架或全域鎖。

## 驗證與交付

- 各入口正常、空資料、晚成功與晚失敗；開新窗並種本題輸入、開後關空、換頁與離開返回。
- 同入口及跨入口交錯，舊先回、新先回與最新失敗；即時 hash 變更但 router 尚未執行。
- 同頁背景重畫允許已接受意圖完成；重畫後舊事件零 GET、不干擾新意圖；根節點替換、有效失敗重試。
- 每題合成資料獨立，初載無寫入且帳本保留；辨明設定頁初載與管理入口各自 GET，不只等待 bootSettled。
- 每個入口接線與共享排序、彈窗觀察、hash、舊入口資格分別做有效突變；語法錯、環境錯或逾時不算產品斷言。
- 三關、全部路由原生重載與合成情境後，官方 Grok 複審、逐項核收、正式合併及工具驗收；不冒稱本人實看。
