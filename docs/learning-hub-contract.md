> 影片線的規矩層、EPxx 腳本、詞彙短片治理**全部住在那裡**，本 repo 不留副本。
>
> ⚠️ **本檔刻意不放在 `docs/contracts/`**：那個目錄的定義是「AGENTS.md 同步點清單的**領域拆分**」
> （見 `docs/contracts/README.md` 開宗第一句），而本檔不是從同步點拆出來的，是一份**跨 repo 交付契約**。

> ⚠️ **跨 repo 同步沒有機械閘**：本 repo 的考題掃不到影片 repo，反之亦然。
> 改到兩邊共用界線的人，自己負責兩邊都改。

## 一、影片線交什麼（交付清單）

影片線累積成品後，由 Claude／Codex 從 Notion 生產看板同步進本 repo。每支影片一列：

| 欄位 | 說明 |
|---|---|
| YouTube 影片 ID | 嵌入用；未上架時留空 |
| 標題 | 上架用的正式標題 |
| 主題領域 | 用於詞彙牆的瀏覽分類 |
| 難度 | 基礎／進階（詞彙牆篩選用） |
| 三題測驗 | **僅 EPxx 正片有**；詞彙短片刻意不排入（500 支×3 題的審題量不進主產線） |

**時機**：詞彙短片先不進學習專區；累積 50–100 支後才開「詞彙牆」次階段。

## 二、webapp 怎麼接（v0 規格，最小可行）

> 以下整節自影片線規則書遷入（原 `docs/教學影片/製作流程與分工.md`「給 Codex 的學習專區規格」節）。
> 遷入的理由：它是**純 webapp 實作規格**，不該跟著影片線搬走；而它是學習專區唯一的成文規格，
> 留在原檔會隨分家一起被刪掉。

- **新「學習」區塊**：集數列表 → 點開＝影片播放器＋該集三題測驗＋答對亮徽章。
- **影片來源**：**YouTube 嵌入**——iframe 用 `https://www.youtube-nocookie.com/embed/<影片ID>`（隱私增強模式，按播放前不種 cookie）。不需要本機影片資料夾或新 static 路由。
- **集數 metadata**：靜態檔（如 `public/learn/episodes.js`——id、標題、**youtubeId**、三題測驗），純內容、可進 git。
- **學習進度**：存 DB 新集合（每集：是否看過、測驗是否通過、徽章）——照鐵則走 schema 白名單＋欄位所有權表補列＋隔離 DB 測試。
- **互動**：vanilla JS module（`public/modules/learn.js`），不引框架，遵守現有 UI 規範（色票、.stat/.num/.empty…）。
- **降級**：斷網或 youtubeId 未填時顯示白話空狀態（「影片還沒上架」／「目前離線，附 YouTube 連結」），不能整頁壞掉。學習專區是全 app 唯一需要網路的顯示區塊（跟報價抓取同級），屬可接受的本機優先例外。
- **同步點**：實作 PR 必須同步更新 AGENTS.md（YouTube 嵌入慣例、欄位所有權表、學習專區段落）。
- EP01 的測驗題目在 `EP01-生存優先-腳本.md` 第三節。
