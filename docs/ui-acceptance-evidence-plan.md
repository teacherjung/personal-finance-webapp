## 修改與核對

1. 鍵盤門檻列補上證據限制：自動化選值或 DOM 操作不能當作原生選單內部鍵盤操作已驗。
2. UI7 列保留未收官，補上已有部分驗證的來源與範圍；不把未驗到的部分說成完全沒有工作，也不把部分工作說成全站完成。
3. 核對差異、連結與來源原文；保留其他頁面狀態、手機暫停與列印裁決的界線。
4. 依正常三關、Grok 正式複審、掃描可用性核對及合併程序收尾；合併後由分級工具判定是否需要本人驗收，不由文件作者自行免除。
