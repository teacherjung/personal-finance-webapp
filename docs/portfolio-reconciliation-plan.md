# 手動參考數量比對施工計畫

## 目的與依據

讓使用者明確選一筆本頁已載入的持股，手填一筆參考數量，確認比較條件後查看中性算術差額。這是有限的手動比較，不是帳戶對帳或台新自動期末持股匯入。

技術範圍依實際 GPT‑6.1 Sol／xhigh 的手動首版裁示及[施工順序與模組收斂裁示](https://github.com/teacherjung/personal-finance-webapp/pull/718#issuecomment-6276040989)。數量、資格、快照與純 session 收斂於同一模型；日期直接重用已合併的 calendar-date.js，代號直接重用 portfolio-symbol.js。畫面推薦由既有委任代選，不冒稱本人實看。正式三關、Grok 複審、合併與驗收程序照舊。

## 輸入與計算契約

- 持股明細提供次要入口「參考數量比對」。選列初始空白，以唯一有效 id 選一筆；不按代號自選、合併或替缺值補零。
- 開窗時複製本頁 Holding 的 id、symbol、name、currency、quantity、source 為凍結純資料。缺欄保留未知；價格的手動標記不作券商來源。拒絕不支援的資料形狀，不遍歷白名單外欄位。
- 參考側來源名稱、範圍別名、基準日、代號、市場、數量、單位均不預填。來源及別名只是手動描述，不要求完整帳號。單位只收股／單位，不作倍數或商品轉換。
- 同證券與掛牌身分、這一筆 App 列就是比較範圍、數量定義與正負號及單位一致，均須手動確認且初始不勾。代號 trim／大寫一致只是必要條件。身分欄或選列改動清結果及確認，數量或確認改動清結果，明確操作才重新計算。
- 數量每側絕對值最多 1,000,000,000，最多六位有效小數；這是工具範圍。參考只收完整有號十進位文字，可接受前導 U+2212；拒絕空白、科學記號、hex、千分位與尾文。App 僅收有限 number，依保存值驗精度，不猜測浮點雜訊或四捨五入。
- 從十進位位數組六位比例安全整數，相減後以整數位數還原完整數量字串。方向固定為「參考數量 − App 紀錄數量」，中性色與 U+2212，不用金額／損益格式。條件不足只並列數量與具體原因；零差額也不判相符、對平、漏記或出清。
- 參考日期須是真日曆。App 始終說明「本頁已載入的一筆紀錄；部位基準日未記錄」，不拿讀取、開窗、同步或報價時間補日期，也不逕稱日期不同。

## 邊界與生命週期

此功能不新增 API、資料庫／storage／URL／log 寫入或列印輸出；整頁原有資料載入仍存在。輸入文字與選項經 esc，身分查找不用普通物件的原型查表。

沿既有 openModalShell 的鍵盤、背景、關閉與回焦；殼接管後才取 watchModalRoot，配合 dialog／form 身分與 isCurrentRender。每代 portfolio render 開始先 dispose 自己的 session；換頁、關閉、其他窗接管、縮至窄版時解除局部訂閱。失效時仍以原殼 close 的 DOM 身分守衛收尾，不清新窗。只更新本窗結果區及必要確認狀態，避免重畫表單搶焦。

入口預設不顯示，只有 screen 且至少901px顯示。900px以下不留下新入口、間距或 Tab 停點；已開窗縮小則關閉自己的 session。樣式只管此入口，不改手機配置或持股表欄寬、色彩。

## 路徑與驗證

預約路徑完整列在 PR。模型與呈現保持純函式，actions 承接真表單及 dispose；portfolio 只協調資料與接線，tables 只加入入口。契約與責任清單及 PROJECT 同支更新，歷史藍圖不改。

直接題涵蓋精確小數、最大反號差額、零與缺值、輸入形狀、每項獨立資格、日期、XSS、原資料保存及快照隔離。真 DOM 接線驗選列、輸入、計算、清舊、同頁重畫、換頁、關閉、新窗接管、窄版失效與解除訂閱。對承重保護做有效突變：先綠、唯一替換、壞結果紅、還原綠；保存型保留受測操作。

樹外候選證據保留其版本，不將舊題數相加當正式通過。正式合併模組與 import 的新版本須重新驗。原生工具限制仍在，合成 DOM／CSS 不代表原生排版、跨瀏覽器或本人驗收。自動期末來源、可靠帳戶及同口徑部位日期仍另列未完成。
