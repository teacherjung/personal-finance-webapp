## 保存與呈現分開

- 原窗的結構動作及保存入口核原 dialog、控制項、root、完整 hash、導覽與唯讀彈窗觀察，不借後開視窗同名 ID。
- 保存期間防重送，凍結會改動送出快照的操作；取消、關閉及 Esc 保留。成功只關自己的有效原窗，不把保存後追加輸入當作已保存。
- 原窗有效性不因同頁背景重畫而撤銷；整頁重讀另核較新呈現、讀取代次及管理入口意圖。新的管理入口即使尚未開窗或最後失敗，舊保存也不能搶回呈現權。
- 正常成功關原窗後才同步交棒唯讀觀察；新窗、曾開後關閉、導航或較新呈現都不能讓舊工作復活。
- 設定頁呈現後的可編輯控制項收到使用者編輯時，保守標記未存輸入，阻止本分類保存的自動整頁重畫。涵蓋開窗前、POST 中與 GET 中；不讀取或記錄憑證值，不建立全頁值快照，不阻止正常保存與明確導航。
- POST 與後續 GET 的失敗分開。未知傳輸不推定未寫入，不自動重送，不解鎖舊快照盲目重送；保留輸入及唯讀核對途徑。讀回快照不能證明原請求不會較晚完成。

## 證據計畫

先跑原版紅題再實作；兩個分類域均走真 DOM 與獨立合成 LOCAL HTTP 帳本，核端點、payload、單次寫入與正式回讀。覆蓋改名、增刪、排序、結構重繪保字、退路、去空白、重名與原型鍵拒收；核其他交易欄位、另一分類域及設定保存。

延後成功及錯誤分別覆蓋取消、重開同型或其他窗、開後關空、換頁返回、直接 hash 改變、root 替換及同頁背景重畫。交錯涵蓋同／跨管理入口的等待讀取及較新失敗；保存後重讀涵蓋新窗、新頁、新呈現、未存輸入與讀取失敗。未知結果分已寫入與未寫入，不以錯誤文字猜狀態。

有效突變先確認綠色基線，再逐一移除資格、鎖、共享意圖、重讀與未存輸入保護及錯誤分流；保存型保留實際 POST。語法、載入、工具錯誤與程序逾時不當有效紅。未存輸入題每題種新值並核真節點與 control.value。

原生瀏覽器用隔離合成帳本，依實際 ROUTES 重載，再驗兩域正常、新窗、導航及未存輸入／重讀接管代表情境，補獨立有效突變。保留既有分類、內轉、管理入口及刪除考題；正常三關、當版 CI、官方 Grok、逐條對帳及正式合併後工具驗收依程序，不冒稱本人實看或主網站同步。

## 邊界

關窗及換頁不撤回後端已接受的保存。本項不承諾跨分頁、外部寫入或整棵分類樹並行衝突解決；若實證出此類資料遺失另提最小裁示，不擴後端。主網站、真實帳本與憑證、暫停中的其他工作線及既有依賴不動。
