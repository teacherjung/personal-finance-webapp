## 保存與呈現分開

- 原窗結構動作及保存核原 dialog、root、控制項、完整 hash、導覽與唯讀彈窗觀察，不能借後開視窗的同名 ID 操作。
- 保存期間防重送，文字唯讀但仍可聚焦選取，結構與保存按鈕停用；取消、關閉及 Esc 保留。成功只關自己的有效原窗。
- 原窗不因同頁背景重畫失效；自動整頁重讀另核呈現、讀取代次、未存輸入及管理入口意圖。較新入口即使等待或失敗，舊保存也不能搶回畫面。
- 關窗後同步交棒唯讀觀察，後開又關閉的視窗、導航返回及較新呈現都不能使舊工作復活。後續 GET 完成前仍須核資格，不清除新輸入。
- POST 與後續 GET 錯誤分開。POST rejection 不推定未寫入；原快照保持鎖定、草稿可查看選取，關閉後透過原入口 GET 核對，不自動重送或核對。
- 共用 API 無可靠 HTTP 狀態分類，因此明確拒絕也採重開核對，關窗草稿不搬入新窗；這是本支明列的有限退讓，不宣稱修正後原窗重試體驗不變。前端驗證未送 POST 時仍可原窗修正。GET 快照不能證明原請求停止。

## 內轉語意不變

保持有序扁平清單與 `{subs, renames}` payload。role 跟隨原項目改名或排序，不跟位置或名稱；系統 role 項目可改名及刪除，不補回，也不套用收支分類退路鎖。新增項目不產生 role，即使命名為既有系統名稱亦然。renames 只記原項目的實際改名，不把新增或排序當改名。去除首尾空白、重名、至少一項及後端保留字拒收沿用原語意。

## 證據計畫

先以獨立合成 LOCAL HTTP 帳本及真 DOM 證明原版失敗，再有限修正。正常及失敗回應覆蓋關閉、同型重開、他窗、後開又關、hash、換頁返回、root 替換、舊 handler 與替換控制項；核在途防重及結構凍結。交錯涵蓋同／跨管理入口等待及失敗、同頁背景重畫，以及保存後 GET 中的新窗、新頁、新呈現、未存輸入及 GET 錯誤。

逐題核端點、精確 payload、實際 POST 與正式回讀。驗排序不串 role、刪角色不補回、新名稱不生 role、結構重繪保字、改名連動及其他交易欄位／分類保留。未知結果分已寫、未寫、真 400，補重開 GET 失敗後再試，核沒有自動重送。每題獨立種值，不依賴前題。

有效突變先綠後移除資格、鎖、意圖、重讀與未存輸入保護，並驗 role 保存與項目對應；保存型保留真 POST。語法、載入、逾時及工具錯誤不當有效紅。測試 helper 用專屬前綴與成功標記，無設定不啟動、部分設定嚴格拒收；獨立入口子程序的 NODE_TEST_CONTEXT 清理不擴到父環境或主情境。

原生瀏覽器使用隔離合成帳本，依實際 ROUTES 重載，驗正常、角色排序、新窗、導航、未存輸入／重讀接管及未知草稿選取後重開。補獨立有效突變，保留分類保存、內轉語意、管理入口及刪除回歸。當版三關、CI、官方 Grok、獨立對帳、正式合併與工具驗收照程序，不冒稱本人實看或主網站同步。

## 邊界

關窗與換頁不撤回保存，不承諾跨頁籤或整份清單並行衝突解決；後端、role 判準或新恢復介面需求另裁。主網站、真實資料與憑證、暫停中的其他工作線及既有依賴不動。店名規則、體檢及信用卡批次另支處理，不擴全庫掃描。
