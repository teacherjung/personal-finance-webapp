## 單一目的與界線

第一階段只處理各訂閱列表的「考慮停用」標記鈕。保留原 PUT、單一成功通知、頁面重畫與錯誤口徑；失去焦點資格只停止回焦，不撤銷或重送寫入，也不因此取消合法重畫。刪除、表單儲存及記帳入口分開核，不宣稱原24全部完成。

不改金額、日期推進、攤提、歷史凍結、拖曳、後端、App共用介面、共享樣式、手機或雲端。既有表單 routeSeq 消費點不藉本支改成 navSeq；不順修訂閱同日時間線等產品停止線。

## 本人定案的操作

只有操作發起時原標記鈕確實持焦，且在等待期間沒有移焦、換頁、新窗或其他接管，才有一次回焦資格。正常列表完成後按訂閱穩定身分依序選：同筆原標記鈕、同列「編輯」、該頁「訂閱與近期扣款」標題。重排不依列序號找人；沒有唯一、可用的候選就停止。

讀取失敗或空清單沒有上述候選時，沿用現有畫面，本次不另移焦；不擅自選錯誤標題、重試鈕、新增鈕或頁面 h1。若本人要這些情境的新目的地，另附實際畫面定案。獨立 HTML 只作候選演示，不是正式功能修復、回歸通過或本人驗收。

## 技術接法

- 在 subscriptions 模組內保存一次性焦點工作：穩定訂閱身分、原鈕、工作區與 view、操作 token、讀取／呈現代次、routeSeq、navSeq、完整 hash，以及既有 `watchModalRoot()` 的唯讀世代觀察。
- 焦點工作只接自己的最新正常列表提交完成點，事件接好後再核候選；不猜延遲，不輪詢，不新增產品匯出或全域事件。公開 renderer 的既有介面保留，必要私有上下文依技術裁示處理。
- 同頁多代讀取不得讓舊成功或舊失敗移除新畫面、取得回焦權；自動校正遞迴只在仍屬原讀取鏈時傳上下文，不改校正資料規則或請求編排。
- 標記按鈕啟動就取得獨立作業及呈現序號；焦點工作取消或已完成不讓舊PUT晚回重新成為最新呈現。較新標記或外部render接管後，舊作業不另起GET、不寫通知、不整頁重畫。
- 同id的PUT依接受順序局部序列，目標依接受時的可見已確認值取反後凍結；不同id不用等待，序列不等待整頁讀取。每筆接受操作各送一次，不合併、不補發，不加入快按兩次自動反向的樂觀語意。
- 只採正式PUT回音中符合id、嚴格布林及原目標的flag。在目前正常呈現仍有效且模型／列身分唯一時，原地更新同一資料物件、既有圓點與按鈕外觀，保留頁面、列、按鈕、較新通知與焦點；不採舊回音的其他欄位、不動新窗。缺列、重複身分或空白／錯誤頁不補列。
- 仍有效的GET在開始時記確認修訂，提交前只合併之後確認且返回id唯一的flag；資料與事件閉包共用同一呈現模型。GET開始前已確認的值由該次權威讀取提供，確認紀錄在有效讀取收尾或已無提交權時清理，不做永久快取。單純移焦或新窗只取消回焦資格，仍有呈現權的最新作業維持既有GET／重畫。
- 工作建立後的鍵盤、指標、觸控、滾輪、外部移焦、視窗失焦、文件隱藏、換頁、新窗世代、較新呈現及身分失效均按列舉條件取消。原啟動事件不把自己取消；新窗開後又關也不能復活舊工作。
- 自身同步替換列表造成的 blur 只在該次提交內區分；不忽略外部 focusin 或新窗接管。每次候選嘗試前後都重核所有權與有效外部焦點。
- 候選須連線、可見、可用、非 inert 且確能持焦。暫加標題 tabindex 只還原自己新增且未被改寫的值；成功後消費一次，不延伸共用彈窗的一次補償機制。各終止路徑收掉自己的工作與監聽。

## 結果分列

| 結果 | 本階段處理 |
|---|---|
| PUT失敗、原鈕仍持焦 | 沿既有錯誤，不另呼 focus |
| PUT失敗、使用者已移焦 | 保留新焦點 |
| PUT成功、自己的最新正常列表完成 | 有效且本人已核候選時，最多回焦一次 |
| PUT成功、GET或既有校正讀取失敗 | 沿既有錯誤頁，結束焦點工作，不重送PUT |
| 成功空清單、沒有候選 | 保留空白引導，結束焦點工作 |
| 換頁、新窗、外部移焦或較新呈現接管 | 不回焦，不搶接管者 |
| 較舊PUT晚確認，較新標記或外部render已接管 | 只由目前呈現同步已確認flag，不另GET、不換頁／按鈕／通知；沒有合法列就不補列 |
| 舊GET早已在途，之後失去呈現權 | 成功及失敗都不提交，不改較新通知或回焦 |

## 驗證與送審

真DOM題載入正式app與subscriptions模組，從真按鈕發起；每題獨立種資料、控制deferred，斷言本題新值的PUT確有執行，並在自己的GET與重畫後檢查真正activeElement。不以抽取函式、外部示意或假的focus紀錄替代。

涵蓋同鈕、重排、原鈕不可用、列消失、無候選；PUT與GET等待中移焦、寫入與讀取各自失敗、空清單；慢舊成功／失敗、新標記操作、表頭及背景router；完整hash變動與離頁再回；新窗開啟及開後關閉；隱藏、停用、inert、重複身分、focus失敗與重入、暫加屬性還原及監聽收尾。一般夾具提供完整歷史且避開到期校正，另作遞迴相容案例，分清背景請求，不改資料邏輯。

各保護先有綠題，再於獨立副本assert突變目標存在且唯一；保存型保留真操作，只破壞回焦接線、身分、token／代次、route／nav／hash、移焦／新窗取消、失敗／無候選界線、一次性消費或屬性還原，使對應考題紅。既有路由守衛、單一通知、原地重畫、錯誤消毒、重試及空白歷史不得刪弱。

真瀏覽器使用專屬合成資料，以原生Enter／Space驗標記及等待中接管，另核重排、失敗、空白及全部正式路由重載；只記實際測到的瀏覽器與可見性，不冒稱手機、列印或跨瀏覽器完成。正常三關、雲端、本人E10、Grok正式複審及F7保持；通過後再核Gemini合法可用性、留本支紀錄，合併閘與合併後官方分級照常，不預先宣稱免驗收或快速通道。
