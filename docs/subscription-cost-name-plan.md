## 驗證與程序

先用合成資料證明原碼故障，再修正與跑既有訂閱考題、型別及完整檢查。突變先斷言替換目標存在，撤掉名稱保護後回歸必須以預期斷言或例外失敗；不得把載入失敗當有效突變。檢查金額與公式未變、輸入未被修改。

以隔離合成資料在原生瀏覽器核對成本明細及報表入口，保留畫面與錯誤證據，不讀真帳本。完成後由真正 Grok 正式複審，Codex 逐條獨立核收、公開留痕，正式關卡通過才合併。所有掃描維持停止。
