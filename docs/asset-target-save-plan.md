# 資產配置目標儲存的晚回應保護

## 授權與邊界

William 在本次對話指定：「好，就照這樣。先完成資產配置儲存保護，不改畫面外觀，測試完把完整審查訊息和資料給我，我轉貼給 Gemini Argon High 複審。」

只處理 `public/modules/assets.js` 的目標配置儲存接續。不改 HTML 樣板、CSS、計算、資料結構或後端寫入方式；不啟動其他優化。自動 Argon 接線另案暫停，Grok 掃描維持暫停。人工轉交的模型／推理設定與完整回覆待收，不宣稱已完成複審。

## 實作方向

- 送出及回應時核對原彈窗、擁有權與原頁；過期回應不關窗、不通知、不另起頁面重讀。
- 手動關窗比對彈窗節點，避免舊回呼清掉新窗；原窗跨頁後仍可手動關閉。
- 正常成功沿用原寫入、提示及重畫。重畫的資料讀取也要在提交 DOM／圖表前再核對，避免第二段等待侵入新窗或新頁。
- 正常失敗保留輸入、恢復原按鈕與原錯誤提示；重讀亦受同一生命週期限制。分開處理寫入與畫面重讀錯誤，不把成功保存說成寫入失敗。

## 驗證與交付

- 用合成資料與真實前端模組重現成功／失敗的晚回應、關閉重開、其他表單、切走再返回、同頁背景重畫、重讀期間接管、正常成功與重試。
- 至少一項以隔離 LOCAL HTTP 保存後扣住回應，另路回讀證明保存確實完成；不碰真實帳本。
- 先證明新回歸在基底失敗，再驗修法；在樹外副本逐一移除守衛，保留受測操作，確認考題會失敗。
- 跑必要校對、糾察、考試與頁面重載檢查。提供固定版本差異、程式、考題、證據與完整審查要求，由 William 轉交 Gemini Argon High；收到真實回覆後再逐項查證，不預填通過或合併。

## 誠實界線

關窗或切頁不撤回已送出的保存。此項保護後開表單的未存輸入；原表單按儲存後仍可編輯的既有行為不改，也不宣稱這些追加編輯會自動保存。傳輸失敗不能證明後端沒有寫入。其餘表單的晚回應問題仍另列待辦。
