# 全站 UI 驗收表

> 本表用來區分「已有畫面」、「已有驗證」與「William 已驗收」。只有三者都成立，才把一個項目標成完成。

## 狀態定義

| 狀態 | 意義 |
|---|---|
| 已驗收 | William 已確認目前設計可保留，且有相稱的自動或瀏覽器驗證。 |
| 待複驗 | 已有實作或曾合併，但仍缺本輪使用者驗收或全站品質檢查。 |
| 待設計 | 方向尚未決定，或現行設計已明確被退回。 |
| 不適用 | 該頁沒有這項使用情境；需在備註說明理由。 |
