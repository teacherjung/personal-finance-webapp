# 每日洞察引擎（變化引擎）施工計畫

> **活文件**：建立 2026-07-18（「天天愛用」體檢之後）。施工前後的功能微調若動到相關檔案，本計畫隨之更新（見文末變更紀錄）。慣例同 AGENTS.md：一步一 PR、三道關全綠、使用者合併、後端改動合併後重啟。

## 一、為什麼要做（病根一句話）

體檢結論：這個 app 很會說「**現在的狀態**」，但完全不會說「**變了什麼、有什麼新的**」——

- 13 條提醒每天長得一模一樣（看久了變壁紙，就不想開了）；
- 每日自動快照是「**覆蓋**當月那一行」，不是累積 → 系統手上永遠只有每月一個點，連「今天 vs 昨天」都算不出來；
- 報價只在按「更新報價」時抓 → 「今天的漲跌」根本沒被記錄。

使用者拍板的鉤子＝「**打開就知道最近投組變了什麼、app 又給了什麼新見解**」。本計畫就是把時間維度接上去。

## 二、設計原則（施工時隨時對照）

1. **解讀優先於價格**：餵「懂了什麼／該注意什麼」，不餵紅綠數字盯盤（把多巴胺導向健康端，呼應投資最高原則「生存優先」）。
2. **平靜日不造噪音**：沒新鮮事就大方說「今天很平靜 ✓」——安心本身是價值，不製造假緊急。
3. **報喜也報憂**：警示解除要慶祝（「✓ 已解除：本月現金流轉正」），正向回饋只出現一次、不重播。
4. **教育不建議**：訊號解讀用「規則說…」口吻＋`.info-link` 白話彈窗，不給個人化投資建議。
5. **失敗靜默降級**：報價／CAPE 抓不到＝用上次的值照常顯示（本機優先、離線可用），絕不擋開機、絕不跳錯誤打擾。

## 三、完工後的總覽長相（文字示意）

```
┌ 總覽 ──────────────────────────────────────
│ 淨資產  1,234.5 萬     ▲今天 +0.4%  ▲本週 +2.3%
│ [走勢線]               上次開啟：3 天前
│
│ 📬 自從你上次看（7/15 以來）
│   🆕 ECY 由「常態」→「加碼」：美股便宜了一點（白話解釋）
│   🆕 台積電穿透曝險 14.2%，離 15% 上限剩 0.8%
│   ✓ 已解除：本月現金流轉正 👍
│   ▸ 持續中 3 項（收合）
│
│ [四張 KPI 卡照舊，各加 Δ 小字]
│ [資產配置] [淨資產走勢]（照舊）
└────────────────────────────────────────────
```

要點：
- Hero 淨資產旁加 **Δ chips**（今天／本週／自上次）＋「上次開啟：N 天前」。
- 「需要處理」升級成「**動態**」三段：🆕 新出現 → ✓ 已解除（報喜）→ 持續中（收合、降視覺權重）。
- 訊號跳檔獨立成卡（ECY 常態→加碼）＋白話解讀彈窗。
- 平靜日整個動態區只剩一行：「今天市場平靜，一切正常 ✓」。

## 六、邊界情境（先想好，別等 Codex 抓）

- **首次執行沒書籤**：全部提醒當「持續中」、不標 🆕（避免假新鮮感洪水）；「自上次」不顯示，只顯示固定窗（今天／本週）。
- **同日第二次開**：🆕 已被上次讀取吸收 → 顯示平靜行＋固定窗照常。誠實，不造假新鮮。
- **報價抓不到／離線**：用舊價寫日線（原則 5），畫面照常，角落標報價時間。
- **舊資料沒日線**：本週／本月 Δ 找「最接近的既有日」比；資料不足就不顯示該窗（不硬算）。
- **平靜判定**：無 🆕、無 ✓、無跳檔、且 |今日 Δ| 低於門檻（初值 0.3%，施工時可調）→ 平靜行。
- **dailyValues 大小**：一天一行、永久保留（一年 365 行，SQLite 毫無壓力）；未來要壓縮再議。
- **書籤更新時機**：`GET /api/insights` 被讀取＝視為「看過了」，當下更新書籤。只有總覽會呼叫它。
