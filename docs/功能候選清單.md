# 功能候選清單（盤點用，使用者逐項挑選）

> 來源＝三路合併：國際主流 app 研究（YNAB/Monarch/Copilot/Actual/Firefly/Kubera/Empower/ProjectionLab/PocketSmith/Rocket Money/MaxRewards/Snowball/Sharesight）＋台灣 app 研究（麻布記帳/MOZE/CWMoney/記帳城市/簡單記帳/國泰 CUBE/Richart/Cardli/訂閱通）＋Claude 對本 app 現況的建議。
> 標記：⭐＝Claude 推薦（價值/成本比高）；工程量 小＝約半天、中＝1–3 天、大＝一週級；✅＝使用者已選。
> 版面優化統一延後（使用者定）；教學功能線在功能齊備後導入。

## Claude 的策略建議（口頭討論用）
1. **預算（2-1＋2-2）是目前最大的功能缺口**——記帳已經很強（匯入+學習），但「記了之後呢」缺一塊：預算讓記帳變成行為改變。也是未來教學（信封袋法）的最佳掛點。
2. **規則引擎（2-3）是現有帳單匯入的天然升級**——學習表已在做「商家→分類」，規則引擎把它變成可管理、可回溯的系統。
3. **時間軸（1-4）成本低、體驗好**——卡片/訂閱/保費提醒都已存在，只是把它們排到一條時間線上。
4. **月度回顧（1-2）幾乎零新資料**——快照＋分類統計就能生成，效果/成本比極高；年度回顧（1-3）等資料累積一年後做正好。
5. **電子發票 API（8-13）是台灣殺手級**，但要申請與較大工程，建議列願望清單、多人化後做。
6. 與「生存優先」哲學最搭的：緊急預備金儀表（1-7）、壓力情境卡（4-12）、緊急資訊表（7-8）。
