## 一集的生產線（照 EP01 腳本檔的格式重複）

選題（Grok 雷達：散戶最近在誤解什麼）→ Claude 腳本初稿 → 老師審改 → Grok 查核 → Gemini 圖卡 →
HeyGen 成片 → CapCut 字幕輸出 → **上傳 YouTube**（先「非公開」自檢再轉公開）→
影片 ID 填進集數 metadata → 上架學習專區＋配三題測驗

## 鐵則（做影片專用，違反任一條就停下來）

1. **影片檔不進 git、也不放 repo**：成片直接上傳 YouTube，webapp 用嵌入播放；原始 mp4／素材自行存雲端或外接碟備份。repo 只進腳本 `.md` 與集數 metadata（含 YouTube 影片 ID）。
2. **app 截圖一律用合成測試資料**（STORE_FILE 指暫存 DB 的那套）——影片會公開上 YouTube，真實金額／帳號／餘額絕不可入鏡。
3. 腳本裡引用的規則數字（個股 5%、國家 15%、槓桿 1.3 倍…）以**規則書／AGENTS.md 投資語意**為準，改規則時要回頭改還沒發佈的腳本。
4. 每集腳本檔都放 `docs/教學影片/`，檔名 `EPxx-主題-腳本.md`，內含台詞、畫面指示、三題測驗、更新紀錄。

## 給 Codex 的學習專區規格（v0，最小可行）

- **新「學習」區塊**：集數列表 → 點開＝影片播放器＋該集三題測驗＋答對亮徽章。
- **影片來源**：**YouTube 嵌入**——iframe 用 `https://www.youtube-nocookie.com/embed/<影片ID>`（隱私增強模式，按播放前不種 cookie）。不需要本機影片資料夾或新 static 路由。
- **集數 metadata**：靜態檔（如 `public/learn/episodes.js`——id、標題、**youtubeId**、三題測驗），純內容、可進 git。
- **學習進度**：存 DB 新集合（每集：是否看過、測驗是否通過、徽章）——照鐵則走 schema 白名單＋欄位所有權表補列＋隔離 DB 測試。
- **互動**：vanilla JS module（`public/modules/learn.js`），不引框架，遵守現有 UI 規範（色票、.stat/.num/.empty…）。
- **降級**：斷網或 youtubeId 未填時顯示白話空狀態（「影片還沒上架」／「目前離線，附 YouTube 連結」），不能整頁壞掉。學習專區是全 app 唯一需要網路的顯示區塊（跟報價抓取同級），屬可接受的本機優先例外。
- **同步點**：實作 PR 必須同步更新 AGENTS.md（YouTube 嵌入慣例、欄位所有權表、學習專區段落）。
- EP01 的測驗題目在 `EP01-生存優先-腳本.md` 第三節。
