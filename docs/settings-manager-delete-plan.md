## 技術邊界

指定 GPT-6.1 Sol／xhigh 已裁定有限範圍，原題與逐字裁示在本支 PR 公開配對。原窗、原列、完整 hash、導覽及彈窗所有權須在確認前後與續行核對；每窗一把在途鎖，防止同列或不同列重送。取消後可再次操作。

成功只更新原窗清單，不重新開窗；晚成功或晚失敗不得通知、重畫新窗或追加讀取。關窗不撤回已送出的刪除。有效傳輸未知不得冒稱失敗未寫入或成功，不自動再送刪除；以既有唯讀端點核對，讀取失敗須保留可辨認的未同步終態。讀回快照不保證原未知請求不會稍後完成。

銀行鍵與文字欄位加鍵為穩定身分，不以漂移列索引決定刪除對象；文字空白值與相同鍵不同欄位須保留。不得回改已存交易或擴為跨頁籤全域鎖。

## 驗證與交付

- 完整模組、獨立合成 LOCAL HTTP：正常刪除與取消、確認期間換窗或換頁、防重入、脫離 DOM 舊列、連續刪除。
- 晚成功／失敗、開新窗再關閉、即時 hash 與離開返回、同頁背景重畫；每題種新輸入確認保存。
- 未知結果在後端已寫入與未寫入、讀回失敗及失格續行；不得重送 POST，其他規則與舊交易保存。
